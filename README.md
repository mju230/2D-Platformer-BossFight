# 2D Platformer — Boss Fight

사이버펑크 배경의 2D 액션 플랫포머 개인 프로젝트입니다.

캐릭터 이동과 사격, 사다리 등반, 적 순찰 행동과 보스전을 구현했습니다. **1스테이지는 보스전까지 구현했습니다. 2스테이지는 일부 제작했으나 완성하지 않은 상태로 개발을 마무리했습니다.**

- **개발 형태:** 개인 프로젝트
- **개발 환경:** Unity `2022.3.19f1` / C#
- **현재 상태:** 개발 종료 - 1스테이지 및 보스전 구현, 2스테이지 미완성

## 주요 기능

- 캐릭터 이동·달리기·점프·사다리 등반·앉아쏘기
- 피격 방향에 따른 넉백과 일정 시간 무적 처리
- 체크포인트 갱신과 낙사 후 복귀
- 드론·슬라임의 순찰 행동과 고정형 터렛
- 공격 예고와 연속 사격을 사용하는 보스

## 핵심 구현

### 캐릭터 조작과 사격

Input System으로 입력을 받고, `Rigidbody2D`의 속도를 조절해 이동과 점프를 처리합니다. 지면 감지는 `Physics2D.OverlapCircle`과 지면 레이어를 사용합니다.

사다리에 올라간 동안에는 중력을 끄고 수직 이동을 적용하며, 사다리를 벗어나면 기존 중력을 복원합니다.

사격 시에는 캐릭터가 바라보는 방향으로 총알을 발사합니다. 앉은 자세에서는 별도의 발사 위치를 사용하며, 발사 간격을 제한해 연속 입력에 따른 발사 빈도를 제어합니다.

### 피격·넉백·무적 처리

공격자와 플레이어의 상대 위치를 비교해 넉백 방향을 결정합니다.

넉백 중에는 일반 이동 처리가 물리 속도를 덮어쓰지 않도록 제한합니다. 피격 후에는 일정 시간 추가 피해를 막고, 스프라이트를 깜빡여 무적 상태를 표현합니다.

### 보스 상태 전환

보스는 `enum`과 `switch`, 코루틴을 조합해 다음 흐름으로 동작합니다.

**순찰 → 공격 예고 → 연속 사격 → 쿨다운 → 순찰**

플레이어가 공격 범위에 들어오면 몸 색상을 변경해 공격을 예고합니다. 예고가 끝난 시점의 플레이어 방향을 계산한 뒤, 해당 방향으로 여러 발을 연속 발사합니다.

체력이 0이 되면 실행 중인 코루틴을 중단하고 충돌·물리 처리를 비활성화한 뒤 사망 연출을 재생합니다.

### 보스전 구역과 카메라

일반 구간에서는 카메라가 설정된 범위 안에서 플레이어를 따라갑니다.

보스 구역에 진입하면 카메라를 고정하고, 화면 폭을 기준으로 플레이어의 좌우 이동 범위를 제한합니다. 보스를 처치하면 오른쪽 이동 제한을 해제하고, 플레이어가 구역을 벗어나면 다음 씬으로 전환합니다.

현재 다음 스테이지로 연결되는 2스테이지는 미완성입니다.

### 적 행동

하나의 `Enemy` 클래스에서 `EnemyType`에 따라 행동을 구분하고, 체력 감소와 사망 처리를 공통으로 관리합니다.

| 적 종류 | 행동 |
|---|---|
| 드론 | 지정된 구간을 순찰하며, 방향 전환 시 스프라이트를 순서대로 교체해 회전 표현 |
| 슬라임 | 시작 위치를 기준으로 좌우 왕복 |
| 터렛 | 이동하지 않는 고정형 적 |

### 체크포인트와 배경

체크포인트에 도달하면 복귀 위치를 갱신합니다. 낙사 시 체력이 남아 있으면 저장된 위치로 돌아가고, 체력이 소진되면 게임 오버 화면으로 전환합니다.

배경은 카메라 이동량에 서로 다른 배율을 적용하는 패럴랙스 방식으로 움직입니다.

## 문제 해결

### 앉아쏘기·점프샷 이후 지상 사격 모션이 재생되는 현상

**현상**

앉거나 점프한 상태에서 사격하면, 일어나거나 착지한 뒤 지상 사격 모션이 뒤늦게 재생됐습니다.

**원인 확인**

Animator에서 발사 후에도 `Fire` 트리거가 남아 있는 것을 확인했습니다.

사용한 에셋은 앉기·점프 애니메이션 자체가 사격 자세여서 별도의 지상 사격 전환을 사용하지 않았지만, 코드에서는 발사할 때마다 `Fire`를 설정하고 있었습니다. 이 트리거가 남아 있다가 지상 상태로 돌아온 뒤 전환에 사용됐습니다.

**수정**

앉기·점프 상태에서 `ResetTrigger("Fire")`를 호출하도록 조건을 추가했습니다. 총알 생성 로직은 유지하면서, 해당 상태가 끝난 뒤 불필요한 지상 사격 전환이 발생하지 않도록 처리했습니다.

## 현재 범위와 개선 가능한 부분

- 1스테이지는 보스전까지 구성했으며, 2스테이지는 미완성입니다.
- 플레이어의 입력·이동·공격·피격 처리가 한 클래스에 모여 있어, 기능 확장 시 역할 분리를 검토할 수 있습니다.
- 총알과 일부 이펙트는 `Instantiate`와 `Destroy`로 생성·제거하며, 오브젝트 풀링은 적용하지 않았습니다.
